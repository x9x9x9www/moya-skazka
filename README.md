# 🪄 «Моя сказка» — Telegram Mini App

> **Персонализированные сказки для детей 2–6 лет с заботой и волшебством.**  
> Полнофункциональный MVP, спроектированный строго по техническому заданию `Moya_Skazka_TZ_Telegram_Mini_App.docx` и дизайн-макетам экранов `описание.jpg` (экраны 1–12).

> **Текущий статус (демо).** Рабочий контур сейчас: React Mini App + локальный AI-мост `bot/bot.mjs` + Wellflow. Книги, дети и баланс пока живут в `localStorage`; оплата Stars — демо-заглушка; backend `apps/api` и PostgreSQL подготовлены, но ещё не являются источником истины. Генерация уже использует новый `packages/story-engine`: 3D Pixar-иллюстрации, обложка + 4 сцены, character bible и валидация. Ключи Wellflow — только на сервере. Подробный план миграции — в конце README.

## 🌟 Ключевые возможности

1. **Персонализация под ребёнка:**
   * Профили детей (возраст 2–6 лет, интересы, характер, параметры внешности без загрузки фото).
   * Автоматическая адаптация языка, длины предложений и сюжета под 3 возрастные группы (2–3 года, 4–5 лет, 6 лет).
2. **Педагогические вопросы для обсуждения (Раздел 6 ТЗ):**
   * Врезка «Поговорите с ребёнком» после 2-й, 4-й сцены и в финале с подсказками для родителя.
   * Вопросы на развитие эмоционального интеллекта, логики, эмпатии и смелости.
3. **Модель монетизации и Telegram Stars (Раздел 8 ТЗ):**
   * **Первая сказка бесплатно:** ровно одна текстовая сказка на родительский аккаунт (атомарный маркер `free_text_claimed_at`).
   * **Книжные кредиты:** 199 ₽ (≈ 400 ⭐) за 1 иллюстрированную книгу, 799 ₽ (≈ 1 600 ⭐) за набор из 5 книг со скидкой 20%.
   * **Улучшение книги:** апгрейд существующего бесплатного текста до иллюстрированной книги (обложка + 4 иллюстрации) без изменения текста и вопросов.
   * **Безопасность транзакций:** защита от гонок кликов через `SELECT ... FOR UPDATE`, идемпотентность вебхуков по `telegram_charge_id`, автовозврат зарезервированного кредита при сбое AI.
4. **Реферальная программа с антифродом (Раздел 5.4 и 15 ТЗ):**
   * Персональный deep link `t.me/MoyaSkazkaBot?startapp=ref_<id>`.
   * +1 подарочный кредит начисляется пригласившему **только после первой подтверждённой оплаты** приглашённого друга.
   * Запрет самоприглашений и повторных бонусов.
5. **AI-генерация через Wellflow + собственный Story Engine:**
   * Текст: `gemini-3.8-flash` (по умолчанию), `nano-banana-2` для иллюстраций.
   * `packages/story-engine`: Story DNA, character bible, 3D Pixar-стиль, обложка + 4 сцены, валидация JSON, удаление вопросов из текста сцен и length repair.
   * Ключи Wellflow живут только в серверном `.env`; в клиентском бандле их нет.
   * Автоматический fallback на процедурную сказку и `MockAIProvider` для локальной разработки.

## 🗄 База данных (14 таблиц со связями и индексами)

1. `users` — родительские аккаунты, `telegram_user_id (UNIQUE)`, атомарный маркер `free_text_claimed_at`.
2. `child_profiles` — профили детей (`age 2..6`, интересы, характер, внешность).
3. `books` — сказки (`draft` → `text_generating` → `text_ready` → `illustrations_queued` → `illustrating` → `illustrated`).
4. `book_scenes` — ровно 4 сцены на книгу (`UNIQUE(book_id, scene_index)`), текст, промпт и привязка к ассету.
5. `book_questions` — педагогические вопросы для обсуждения (после 2-й, 4-й сцены или в финале).
6. `daily_ideas` — 1 персональная идея на ребёнка в сутки (`UNIQUE(child_id, local_date)`).
7. `assets` — приватные иллюстрации и обложки, хранение стоимости генерации `generation_cost`.
8. `orders` — заказы Telegram Stars с защитой от дубликатов (`telegram_charge_id UNIQUE`, `idempotency_key UNIQUE`).
9. `credit_ledger` — неизменяемый журнал операций баланса (+1, +5, -1) с аудитом.
10. `credit_reservations` — атомарные резервации кредитов на генерацию (`RESERVED` → `CONSUMED` / `RELEASED`).
11. `referrals` — приглашения пользователей (`invitee_id UNIQUE`, запрет самоприглашений).
12. `referral_rewards` — награды за первую оплату друга (`referral_id UNIQUE`, `order_id UNIQUE`).
13. `jobs` — очередь задач фоновой генерации с неблокирующей выборкой `SELECT ... FOR UPDATE SKIP LOCKED` и retries.
14. `events` — продуктовая воронка и аудит (`app_opened`, `checkout_started`, `payment_confirmed` и др.).

## 🚀 Быстрый старт демо (текущий контур)

```bash
# 1. AI-мост: Wellflow + локальные картинки
npm run bot

# 2. UI (в отдельном терминале)
npm run dev:web
```

Для локальной проверки без Telegram и туннелей:

```bash
SKIP_TELEGRAM=true SKIP_TUNNELS=true PUBLIC_BRIDGE_URL=http://127.0.0.1:4040 node bot/bot.mjs
npm run dev:web
# открыть http://localhost:5173/?api_url=http://127.0.0.1:4040
```

Ключи `WELLFLOW_TEXT_KEY` и `WELLFLOW_IMAGE_KEY` должны быть в корневом `.env` и не попадать в git.

## 🚀 Быстрый старт

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

Убедитесь, что у вас установлен Docker, и выполните:

```bash
# 1. Запуск всех сервисов (PostgreSQL + API + Web)
docker compose up -d --build

# 2. Проверка статуса контейнеров
docker compose ps
```

* **Frontend Mini App:** [http://localhost:5173](http://localhost:5173) или [http://localhost](http://localhost)
* **Backend API:** [http://localhost:4000/api/v1](http://localhost:4000/api/v1)
* **Swagger документация:** [http://localhost:4000/docs](http://localhost:4000/docs)
* **PostgreSQL:** `localhost:5432` (пользователь: `postgres`, пароль: `postgrespassword`, база: `moya_skazka`)

### Вариант 2: Локальный запуск без Docker

#### Шаг 1: Установка зависимостей
```bash
npm install
```

#### Шаг 2: Настройка переменных окружения
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```
В файле `.env` уже указан ваш ключ Gemini API и тестовые параметры.

#### Шаг 3: Инициализация базы данных
Если у вас запущен локальный PostgreSQL:
```bash
npm run prisma:generate --workspace=@moya-skazka/database
npm run migrate --workspace=@moya-skazka/database
```
*Или выполните скрипт миграции напрямую:*
```bash
psql -U postgres -d moya_skazka -f packages/database/prisma/migrations/0001_initial_schema.sql
```

#### Шаг 4: Запуск бэкенда и воркера
```bash
# Запуск Fastify API и фонового воркера задач
npm run dev --workspace=@moya-skazka/api
```

#### Шаг 5: Запуск фронтенда Mini App
В отдельном терминале:
```bash
npm run dev --workspace=@moya-skazka/web
```
Интерфейс откроется по адресу: [http://localhost:5173](http://localhost:5173).

## 🧪 Автотесты

```bash
# Story Engine: промпт, character bible, валидация, вопросы, 3D-промпты
npm run test --workspace=@moya-skazka/story-engine

# API: контрактные проверки + статические тесты промпта
npm run test --workspace=@moya-skazka/api
```

Сейчас это **15 unit-тестов Story Engine** и **17 API-тестов + 1 live-тест, который пропускается без `RUN_LIVE_AI_TESTS=true`**. Тесты в `acceptance.spec.ts` — контрактные симуляции, а не интеграционные проверки с PostgreSQL; полноценные интеграционные тесты появятся вместе с backend-миграцией.

### Проверяемые сценарии приёмки:
1. `Пункт 1`: Однократность бесплатной книги (повторная попытка возвращает `403`).
2. `Пункт 2`: Адаптация сложности текста и вопросов под возраст (2–3 года, 4–5 лет, 6 лет; возможность отключения вопросов).
3. `Пункт 3`: Апгрейд бесплатной книги 5 изображениями без изменения зафиксированного текста.
4. `Пункт 4`: Начисление кредитов (+1 за одиночный SKU, +5 за пакет).
5. `Пункт 5`: Идемпотентность вебхука Telegram Stars (защита от дубликатов по `telegram_charge_id`).
6. `Пункт 6`: **Стресс-тест гонки:** при балансе 1 кредит два параллельных клика `Promise.all` списывают ровно 1 кредит благодаря `SELECT ... FOR UPDATE`.
7. `Пункт 7`: Реферальная награда начисляется строго один раз за первую подтверждённую оплату друга.
8. `Пункт 8`: Запрет самоприглашения (`inviter_id !== invitee_id`).
9. `Пункт 9`: Автоматическое освобождение резерва кредита при фатальной ошибке генерации AI.
10. `Пункт 10`: Повторное открытие готовой книги из библиотеки без списания баланса.
11. `Пункт 11`: Защита от чужого ID (Ownership Check возвращает `403 Forbidden`).
12. `Пункт 12`: Каскадное удаление аккаунта и связанных данных по 152-ФЗ / GDPR.
13. `Пункт 13`: Соответствие цен каталогу (199 ₽ = 400 ⭐, 799 ₽ = 1 600 ⭐).
14. `Пункт 14`: Аудит администратора (фиксация затрат AI, ошибок и обязательной причины корректировки баланса).

## ⚙️ Настройка в Telegram (@BotFather)

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте нового бота через `/newbot`.
3. Включите Mini App через `/newapp`:
   * Выберите созданного бота.
   * Укажите название: `Моя сказка`.
   * Описание: `Персональные иллюстрированные сказки для детей 2–6 лет`.
   * URL приложения: укажите публичный HTTPS-адрес вашего веб-приложения (например, через ngrok для локальной разработки: `https://<hash>.ngrok-free.app`).
4. Настройте кнопку меню бота через `/setmenubutton`.
5. Для приёма оплат в Telegram Stars в BotFather выберите:
   * `/mybots` → Выберите бота → **Bot Settings** → **Payments** → Включите **Telegram Stars**.
6. Реферальные ссылки работают автоматически через нативный механизм `startapp`:
   `https://t.me/<username_бота>?startapp=ref_<user_id>`.

## 🛡 Безопасность и соответствие законодательству

* **152-ФЗ и приватность:** не собираются фотографии детей, биометрические данные или контакты. Внешность персонажей настраивается параметрами.
* Реализован эндпоинт `POST /api/v1/privacy/delete` для гарантированного удаления персональных данных.
* **Защита от промпт-инъекций:** строгая валидация и очистка всех пользовательских полей (имя, особые пожелания) через Zod регулярные выражения.
* **Приватное хранение ассетов:** иллюстрации хранятся в защищённом хранилище и отдаются клиенту только по краткоживущим подписанным URL (signed URLs).
